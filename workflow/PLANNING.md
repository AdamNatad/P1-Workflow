# Planning

The roadmap: milestones, and the phases inside each. Phases, scope and order only. The owner sets
the schedule, so this file carries no dates, durations or estimates.

A milestone is a release people can use, except 0.1, which plans and designs it. A phase is a piece
of a milestone that can be built, checked and finished on its own, and leaves a working project.
`TASKS.md` breaks the current phase into tasks.

### Milestone 0.1 — Planning and design

- **Scope:** the workflow in place with the project's name, the product plan (`PRODUCT.md`), this
  roadmap, design options for the owner to pick from, the stack for the owner to approve, the
  license, and a launcher.
- **Not in this milestone:** product code beyond what the launcher needs to start.
- **Done when:** every item under Milestone 0.1 in `ACCEPTANCE.md` is checked.
