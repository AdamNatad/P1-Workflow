# Milestone 0.1 records

Timestamped records for the current milestone, each from `../../notes/templates/record.md` and
named `YYYY-MM-DD-HHMMSS-topic.md`:

- plans (`kind: planning-record`) and implementation records;
- lane packets, `YYYY-MM-DD-HHMMSS-packet-<lane>-<topic>.md`, from
  `../../notes/templates/lane-packet.md`, each with its hand-over beside it,
  `YYYY-MM-DD-HHMMSS-handoff-<lane>.md`.

Records support `TASKS.md` and never replace it. When the milestone is finished, its records move to
`../../archive/0.1/`, and the next milestone gets its own folder here, such as `0.2/`.
