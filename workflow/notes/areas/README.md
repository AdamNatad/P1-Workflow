# Areas

One note per code module, named after its folder: `src/modules/billing-invoices/` gets
`billing-invoices.md`. An agent reads a module's note before it changes that module.

Each note says:

- **Owns:** what the module is responsible for, and what it is not.
- **Files:** its main files and what each does.
- **Entry points:** what other modules call, and how.
- **Data:** what it reads and writes (`DATABASE.md`).
- **Tests:** where they are and how to run them.
- **Watch out:** anything easy to break.
